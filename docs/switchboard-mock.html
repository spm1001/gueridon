⑤ The resumed Claude gets a transition preamble: what surface it left, what it wakes on, which wallet, how long it slept. No gear-slip.
One driver per session: cold → resume · held on tube → graceful end, then resume (baton-pass) · held remotely → fork or archive-first. Cross-wallet always forks — the original transcript is never touched.

The wallet sheet — an open, config-driven list (a lane = a name + an env block), never two hardcoded buttons. Same sheet for pickup and for new launches.

What each tap does:
sameer@ (same wallet, cold) → true resume: same transcript, continued in place, history replayed in Guéridon's UI.
vertex / family@ (cross-wallet) → forced fork: new uuid inheriting the conversation; the original stays byte-identical for its home surface. The fork appears in SESSIONS badged “⑂ of Mawitu pickup”.
seat 3 → nothing until its config exists; then it's a family@-style row.
Every tap injects the transition preamble (⑤). If the session were held rather than cold, the same-wallet row would switch verb to baton-pass.

The badges — what today's UI does with each of these

  • ①Your family@ session, busy for 18 hours — today it shows as anonymous “local”, wallet invisible even to claude agents. Here it's a first-class lane.
  • ②Phone-created RC-server children — today entirely invisible (the scanner matches the wrong process name; live bug, fix filed as gdn-zahidu). Two of yours were missing this morning.
  • ③Cowork sessions have no local title anywhere the CLI looks — but the Desktop sidecar has a human one, free for the reading.
  • ④Teleport sessions are titleless on disk; fallback is the bridge-log title scrape, then the first user prompt. Never a bare uuid in your face.
  • ⑤Your merozu falsifier, both halves: the model is told the transition characteristics; you get from “the one about blah” to a live session in <20s (search + one tap + one lane).

The state machine (what Pick up actually does)

COLD

Transcript on disk, nobody holds it. The common case — and the one a pid-keyed roster can't see at all.

resume⑂ fork (cross-wallet)

HELD — on tube

A live process holds it (terminal, Guéridon, RC child). Baton-pass: graceful end (SIGTERM = a faithful /exit), then force-resume the explicit uuid.

baton-passEnd

HELD — remote

A cloud worker holds the lease; nothing local to signal. Fork it, or archive from the phone first, then resume.

⑂ forkarchive → resume

The invariant: one live driver per transcript, ever. The rule: cross-wallet always forks. The comfort: End is always safe — it's subtraction, and everything stays resumable.
