## For Claudes to come

**A negative result from a search over guessed candidates is a statement about your guesses, not about the system.** This session brute-forced uuid3/uuid5 across five standard namespaces, found nothing, and wrote "not derivable — it must be a lookup" into shipped public guidance. The namespace was reachable and one tried candidate was even correct; what was wrong was the *name* being hashed. The corrective is cheap and general: **when the artefact that computes the answer is on disk — a binary, a bundle, a minified blob — read it before declaring anything unknowable.** Claude Code ships as a ~220MB bundled-Node ELF and `rg -a` greps its embedded JavaScript perfectly well; the whole derivation fell out of three greps. Reach for the source before the search space.

**`--fork-session` is the non-destructive probe for "does this session still resume?"** Testing resumption normally means mutating the thing you are testing, which is why the question usually goes unanswered. A fork proves the history loads while leaving the original byte-identical, so it is safe even when the original may still have a live holder. Used here to settle Cowork resumability in one command; generalises to any resume question.

**Two identifier facts worth holding.** A version-5 UUID in `~/.claude/projects` means a programmatically-spawned session — the harness hashes a caller-supplied id, and a name-based hash is by definition a v5; interactive sessions get v4. And the `{encoded-cwd}` directory scheme is **one-way**: every `/` became a `-`, so any repo with a dash in its name decodes to a path that does not exist (`…-spm1001-mise-en-space` → `.../mise/en/space`). Read `.cwd` from the transcript instead. Both are now in the deglacer skill.
