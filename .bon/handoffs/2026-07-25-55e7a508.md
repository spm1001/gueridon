### Risks

- **`gdn-caguga` blocks the hot-set step of `gdn-sudacu`.** Adding a `claude-remote@` server for a repo under `SCAN_ROOT` (gueridon, infra were the candidates) would **permanently hide that repo from the launcher**, because `gdn-wuvujo` hides repos with a live session and a server always looks like one. ## For Claudes to come

**A substrate check must include the tool's *hidden* surface, because the most useful capability may be the one nothing announces.** `claude remote-control` is absent from `claude --help`'s Commands list, `claude remote` (the working shorthand) appears nowhere in the docs, and no weekly release note announced server mode — so a diligent "read the changelog and `--help`" sweep would have missed it for another month, exactly as it did. What surfaced it was the user pasting terminal output from a command he happened to try. Two habits follow. First, treat the docs *site index* (`llms.txt`) as more complete than the CLI's own help, and diff them: tonight that comparison found `--sandbox`/`--no-sandbox` documented but hidden from `--help`, and `--permission-mode`/`--debug-file` present in `--help` but absent from the docs — the second of which is the security-relevant knob. Second, periodically run `<tool> <subcommand> --help` for subcommands you only half-know, rather than trusting the top-level help to enumerate them.

This is the third consecutive Guéridon plan the substrate has eaten — `/rc` in June, `claude agents` on 2026-07-19, remote launch tonight — and the pattern is now strong enough to be a standing instruction rather than an anecdote: **before building any session-management or launch feature here, spend ten minutes checking whether Anthropic has shipped it, including in surfaces that don't advertise themselves.** Each time, the check deleted more work than it created, and each time shipping less was the right outcome rather than a disappointment. The residual after tonight is genuinely narrow and worth stating plainly so it isn't re-litigated: Guéridon uniquely provides the **Vertex lane** (structurally unreachable by Remote Control, verified at the inference endpoint), **folder creation**, and **any-repo-on-demand** — a `claude remote-control` server is cwd-bound, so covering ~38 repos would need one per repo at ~106 MB each, which is fine for a hot set of three and absurd for the long tail.
